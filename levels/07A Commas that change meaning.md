**Rule:** If a clause tells you *which one*, use *that* with no commas. If it only adds extra information, use *which* with commas. In a list, a comma before the final *and* prevents misreading.

✓ The contract that Omar drafted is late.
✗ The contract which Omar drafted is late. → that

**Brackets test:** put the clause in brackets and read the sentence without it. If the reader still knows which one you mean, the clause is extra: use *which* and commas.
