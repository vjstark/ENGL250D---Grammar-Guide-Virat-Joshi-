Title: Good/Well, Bad/Badly: Test
---
## Question
The editor described the revised schedule ___.

A) good
B) well
Answer: B
Feedback A: *Described* is an action verb, so use the adverb *well*.

## Question
The new client portal looks ___ after the update.

A) good
B) well
Answer: A
Feedback B: *Looks* links the portal to a description, so use the adjective *good*.

## Question
The coordinator handled the last-minute change ___.

A) bad
B) badly
Answer: B
Feedback A: *Handled* is an action verb, so use the adverb *badly*.

## Question
The revised explanation seems ___ to the client.

A) bad
B) badly
Answer: A
Feedback B: *Seems* is a linking verb here, so use the adjective *bad*.

## Inspect: Client update
Document: Email
From: Noor Awan, Legal Assistant
To: You
Subject: Client update
Hint: There are two errors.
Passage:
The revised summary seems {badly => bad | *Seems* links *summary* to a description.} after the new details were added. The coordinator explained the fee change {good => well | *Explained* is an action verb.} before sending the email.
