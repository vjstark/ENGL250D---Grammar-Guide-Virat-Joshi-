## Question
The new associate writes ___.

A) good
B) well
C) goodly
Answer: B
Feedback A: Writes is an action verb, so it needs an adverb. Good is an adjective.
Feedback C: Goodly is not a standard word for this meaning. The adverb form of good is well.
Hint: Is writes an action or a state?

## Question
The coffee in the break room smells ___.

A) good
B) well
C) nicely
Answer: A
Feedback B: Smells is a linking verb here, so it needs an adjective. As an adjective, well means "healthy," and coffee can't be healthy in that way.
Feedback C: Nicely is an adverb, but a linking verb needs an adjective.
Hint: Try the be test: The coffee is ___.

## Question
The witness answered the questions ___.

A) bad
B) badly
C) worst
Answer: B
Feedback A: Answered is an action verb, so it needs the adverb badly.
Feedback C: Worst is a superlative adjective, so it can't describe an action.
Hint: Ask how did she answer?

Re: The new filing system

Subject: Ramsay file update
Penalty: 10
Hint: There are three errors. Check each verb: action or linking?

Passage:
Hi Priya,

Thanks for helping with the Ramsay file. You did {good => well | Did is an action verb, so it needs the adverb well.} on the first draft, and the partner was pleased. I feel {badly => bad | Feel is a linking verb here, so it takes the adjective bad.} that I sent the exhibit list so late.

The client seemed {happily => happy | Seemed is a linking verb. Use the adjective happy.} with the timeline, so the meeting went {well => well | Went is an action verb here, so the adverb well is correct.}.
