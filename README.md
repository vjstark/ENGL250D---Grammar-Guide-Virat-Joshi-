# ENGL250 D - Grammar Guide

A proofreading and grammar practice game set in a pixel-art law office. Play through lessons and tests covering common grammar and usage topics.

## Play

Open [Grammar Guide Game.html](Grammar%20Guide%20Game.html) in a browser to play the included game.

## Build

To rebuild the game after editing its source or lesson files, run `build.cmd` on Windows. The script combines the files in `engine` and `levels` into the standalone HTML game.

See [HOW TO WRITE LEVELS.md](HOW%20TO%20WRITE%20LEVELS.md) for instructions on editing or adding lessons.
